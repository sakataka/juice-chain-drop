# Juice Chain Drop

果物を落として、消して、ジュースを作る落ち物パズルゲームです。

公開URL: https://sakataka.github.io/juice-chain-drop/

## 紹介動画

![Juice Chain Drop 紹介動画](video/output/fruit-puzzle-promo.gif)

## ゲーム概要

`Juice Chain Drop` は、2つ1組で落ちてくる果物を並べ、同じ果物を4個以上つなげて消すパズルゲームです。消した果物はジュースの材料になり、完成したジュースはアイテムとして使うか、出荷してボーナススコアに変えられます。

基本操作はシンプルですが、スコアを伸ばすには、連鎖を狙う、ジュースで盤面を整える、注文に合わせてジュース在庫を残す、といった判断が必要です。

通常プレイのほか、難易度プリセット、チャレンジモード、タッチ操作、BGM/SFX音量調整、連鎖・ジュース・出荷の強調演出、ローカル保存のプレイ記録に対応しています。

## ルール

- 盤面は `6列 x 12行` です。
- 果物は `Apple`, `Orange`, `Lemon`, `Grape`, `Melon`, `Berry` の6種類です。
- 落下する果物ペアを移動・回転させて盤面に積みます。
- 同じ果物が直交方向に4個以上つながると消えます。
- 消去後は重力で果物が落ち、さらに4個以上つながると連鎖します。
- 盤面上部に新しい果物ペアを置けなくなるとゲームオーバーです。
- 即落下中は1マスごとに少しスコアが加算されます。
- 消去スコアは、消えた数、連鎖倍率、ジュース効果の倍率で決まります。
- Next には次の果物ペアが3組表示されます。
- Featured には現在の旬の果物が表示され、旬の果物を消すとジュース進捗が追加で増えます。
- 最高スコア、最高連鎖、プレイ回数、最終プレイ日時はブラウザの `localStorage` に保存されます。

## 難易度

設定パネルから `Easy`, `Normal`, `Hard` を選べます。初期値は `Normal` です。

| 難易度 | 通常落下 | 低速化中 | スコア倍率 | ジュース獲得 |
| --- | ---: | ---: | ---: | --- |
| Easy | 760ms | 1040ms | 0.9x | 3個消すごと |
| Normal | 620ms | 880ms | 1.0x | 4個消すごと |
| Hard | 500ms | 720ms | 1.25x | 5個消すごと |

## モード

設定パネルから次のモードを選べます。

| モード | 目標 |
| --- | --- |
| Normal | 通常のエンドレスプレイ |
| Score Attack | 100万点到達までのタイムを競う |
| Chain Challenge | 60秒以内の最大連鎖を競う |
| Water Cleanup | 最初に出現する水30個を全消去するまでのタイムを競う |

モードごとの進捗と結果はサイドパネルの `Challenge` に表示されます。

## 操作方法

| キー | 操作 |
| --- | --- |
| `ArrowLeft` | 左へ移動 |
| `ArrowRight` | 右へ移動 |
| `ArrowDown` | 高速落下 |
| `ArrowUp` | 回転 |
| `Space` | 即落下 |
| `Enter` | Start / Restart |
| `P` / `Escape` | Pause / Resume |
| `1` | Apple Juice |
| `2` | Orange Juice |
| `3` | Lemon Juice |
| `4` | Grape Juice |
| `5` | Melon Juice |
| `6` | Berry Juice |

盤面下のタッチ操作ボタンから、左右移動、回転、高速落下、即落下、ポーズ/再開も実行できます。通常ジュースは、サイドパネルの各ボタンをタッチして使用できます。

## 設定

設定パネルでは次を変更できます。設定値はブラウザの `localStorage` に保存されます。

- 難易度
- モード
- 出荷間隔秒数（`0`で出荷なし）
- 演出軽減
- SFX音量
- BGM音量
- 操作説明の確認

サウンドは `Sound On / Sound Off` で切り替えます。BGMはブラウザの自動再生制限に合わせ、サウンド有効後のユーザー操作をきっかけに開始します。

## ジュースアイテム

果物を一定数消すごとに、その果物のジュースを1個獲得します。必要数は難易度によって変わり、所持数に上限はありません。

| ジュース | 効果 |
| --- | --- |
| Apple Juice | 中心周囲 `3 x 3` の果物を消す |
| Orange Juice | 中心行の果物を消す |
| Lemon Juice | 中心周辺の最大4個を現在の軸果物に変える |
| Grape Juice | 中心列の果物を消す |
| Melon Juice | 次の1手だけ落下を遅くし、その手の消去スコアを `1.5x` にする |
| Berry Juice | 盤面で最も多い果物に、中心周辺の最大5個を変える |

ジュース効果の中心は、現在落下中の果物ペアの軸セルです。中心が盤面外にある場合は、最も近い有効セルに補正されます。

ジュースを使うと、効果で変化したセル数やジュースの種類に応じた使用ボーナスも入ります。

## 出荷

出荷間隔の初期値は45秒です。プレイ中だけタイマーが進み、完成済みジュース在庫を全て消費してボーナススコアへ変換します。途中までたまっているジュース進捗は出荷されず、そのまま残ります。出荷間隔を`0`にすると出荷は発生しません。

出荷スコアは `160 x 在庫数 x 在庫数 x 難易度スコア倍率 x 出荷コンボ倍率` です。

出荷に成功するたびに出荷コンボが増え、2回目以降は出荷スコアに `+25%` ずつ倍率が乗ります。倍率は最大 `2.0x` です。出荷タイミングに完成済みジュースがない場合、コンボはリセットされます。

出荷パネルには現在の注文も表示されます。注文で指定されたジュース在庫を満たした状態で出荷すると、通常の出荷スコアに注文ボーナスが加算され、次の注文へ進みます。条件を満たせなかった場合、注文は次の出荷まで残ります。

## 演出

連鎖、ジュース使用、出荷、ゲーム進行段階の変化には、盤面上の光、波紋、スプラッシュ、スコア表示、SFX/BGMの変化が入ります。

- 2連鎖以上ではチェーン数が盤面中央に表示され、3連鎖以上ではより大きなスプラッシュとコンボ演出が入ります。
- ジュース使用時は効果中心から波紋と粒子が広がり、対象セルが少ない場合でも使用したことが分かる演出が入ります。
- 出荷成功時は獲得スコアに加えて、出荷コンボ、倍率、出荷在庫数が表示されます。注文達成時は `ORDER COMPLETE` として強調されます。
- プレイ時間による進行段階が上がるとBGMテンポが変わり、盤面外周に `SPEED UP` のパルスが出ます。

設定の `演出軽減` を有効にすると、これらの視覚演出は抑制されます。

## 水

水が有効な通常プレイでは、開始10秒後、その後20秒ごとに水が盤面へ落ちます。水は同じ水同士では消えず、隣接する果物グループを消した時に巻き込んで消せます。Water Cleanup モードでは開始時に水が30個出現し、水設定がオフでも有効になります。追加の定期水落下は発生せず、すべて消すまでのタイムを競います。

## 旬の果物

Featured に表示された旬の果物は30秒ごとに切り替わります。旬の果物を消すと、通常の消去数に加えて `消去数の半分切り上げ` のジュース進捗が追加されます。注文に必要なジュースを早く作るための狙いどころになります。

## 開発

依存関係のインストール:

```bash
bun install
```

BGM MIDIの生成:

```bash
bun run generate:bgm
```

ローカル開発サーバー:

```bash
bun run dev
```

本番ビルド:

```bash
bun run build
```

ビルド成果物の確認:

```bash
bun run preview
```

単体テスト:

```bash
bun run test
```

カバレッジ確認:

```bash
bun run test:coverage
```

E2Eテスト:

```bash
bun run test:e2e
```

## デプロイ

`main` ブランチにpushすると、GitHub Actionsでビルドされ、GitHub Pagesにデプロイされます。
