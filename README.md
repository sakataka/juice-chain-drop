# Juice Chain Drop

果物を落として、消して、ジュースを作る落ち物パズルゲームです。

公開URL: https://sakataka.github.io/juice-chain-drop/

## ゲーム概要

`Juice Chain Drop` は、2つ1組で落ちてくる果物を並べ、同じ果物を4個以上つなげて消すパズルゲームです。消した果物でジュースボトルが完成すると、そのボトル自身が `Next Drop` に入り、1マスの落下ピースとして盤面へ戻ってきます。

ゲームの核は `CHAIN → PRESS → JUICE DROP → CHAIN` です。連鎖で果汁をため、ボトルを狙った位置へ落とし、着弾時のジュース効果で盤面を崩して次の連鎖を作ります。Normal と Score Attack では、手数に応じて水が降って果汁を薄めます。水は連鎖やボトルで片付けます。

通常プレイのほか、盤面を自動で遊ぶ `Auto Play`、難易度プリセット、チャレンジモード、タッチ操作、アダプティブBGM、連鎖・プレス・着弾の強調演出、ローカル保存のプレイ記録に対応しています。

## ルール

- 盤面は `6列 x 12行` です。
- 果物は `Apple`, `Orange`, `Lemon`, `Grape`, `Melon`, `Berry` の6種類です。
- 落下する果物ペアを移動・回転させて盤面に積みます。
- 同じ果物が直交方向に4個以上つながると消えます。
- 消去後は重力で果物が落ち、さらに4個以上つながると連鎖します。連鎖は1段ずつ再生され、再生中は次のピースを操作できません。消えるだけの着地は待たずに次へ進みます。
- 盤面上部に新しい果物ペアを置けなくなるとゲームオーバーです。
- 即落下中は1マスごとに少しスコアが加算されます。
- 消去スコアは、消えた数、連鎖倍率、ジュース効果の倍率で決まります。
- `Press Tank` は果物ごとの搾汁進捗を表示します。k連鎖目で消えた果物は1個あたり k 搾汁になり、必要量に達するとボトルが1本完成します。単発の消去より連鎖の方が早くボトルがたまります。
- 盤面の底には、次のボトルに最も近い果物の果汁がたまり、連鎖で波立ちます。積み上がりが危険な高さになると、盤面の縁が赤く点滅します。
- 完成したボトルは `Next Drop` に入り、次の果物ペアを置いたあとに落下ピースになります。
- ボトルは1マスで落下し、左右移動と落下位置の調整ができます。着地すると割れて果汁が広がり、果物ごとの効果を発動します。
- `Next Drop` には、これから落ちる果物ペアとジュースボトルが3手先まで表示されます。
- 最高スコア、最高連鎖、プレイ回数、最終プレイ日時はブラウザの `localStorage` に保存されます。Auto Playで遊んだ回は自分の記録に含めず、Auto Play用の記録に分けて保存します。

## 難易度

設定パネルから `Easy`, `Normal`, `Hard` を選べます。初期値は `Normal` です。

| 難易度 | 通常落下 | 低速化中 | スコア倍率 | ボトル1本の搾汁 | 水の間隔 | 水が1滴増える間隔 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Easy | 760ms | 1040ms | 0.9x | 18 | 6手ごと | 120手ごと |
| Normal | 620ms | 880ms | 1.0x | 24 | 6手ごと | 90手ごと |
| Hard | 500ms | 720ms | 1.25x | 30 | 4手ごと | 60手ごと |

## モード

設定パネルから次のモードを選べます。

| モード | 目標 |
| --- | --- |
| Normal | 通常のエンドレスプレイ。水の圧力あり |
| Score Attack | 5万点到達までのタイムを競う。水の圧力あり |
| Chain Challenge | 60秒以内の最大連鎖を競う |
| Water Cleanup | 最初に出現する水30個を全消去するまでのタイムを競う |

モードごとの進捗と結果はサイドパネルの `Challenge` に表示されます。

## 操作方法

| キー | 操作 |
| --- | --- |
| `ArrowLeft` | 左へ移動 |
| `ArrowRight` | 右へ移動 |
| `ArrowDown` | 高速落下 |
| `ArrowUp` | 回転 |
| `Space` | 即落下 |
| `Enter` | Start / Restart |
| `P` / `Escape` | Pause / Resume |
盤面下のタッチ操作ボタンから、左右移動、回転、高速落下、即落下、ポーズ/再開も実行できます。左右と高速落下のボタンは押し続けると連続で入力されます。ジュースボトルは通常のピースと同じ操作で落下位置を決めます。ボトルは1マスピースのため回転しません。

`Auto Play` を押すと、その場でゲームが始まり、AIが果物ペアとJuice Dropの着地点を選びながら自動でプレイします。AIは選択中のモードに合わせて目標を切り替えます。`Normal` と `Chain Challenge` では盤面が安全な間は連鎖を仕込み、盤面が高くなった時や終盤には発火・盤面回復へ移ります。Auto Playの結果は自分の記録とは別に `Auto Best` として保存されます。もう一度押すと停止し、キーボードやタッチで操作しても即座に手動操作へ戻ります。設定の `Auto Play Pace` から `Calm`, `Flow`, `Rush` を選べます。

## 設定

設定パネルでは次を変更できます。設定値はブラウザの `localStorage` に保存されます。プレイ中に変えた難易度とモードは、進行中のゲームには混ぜず、次のゲームから反映されます。

- 難易度
- モード
- Auto Play Pace
- 演出軽減
- SFX音量
- BGM音量
- 操作説明の確認

サウンドは `Sound On / Sound Off` で切り替えます。BGMはブラウザの自動再生制限に合わせ、サウンド有効後のユーザー操作をきっかけに開始します。

## Juice Drop

果物を一定数消すごとに、その果物のボトルが1本完成します。必要数は難易度によって変わります。完成したボトルは手動で選ぶアイテムではなく、`Next Drop` の落下順へ自動で組み込まれます。

| ジュース | 効果 |
| --- | --- |
| Apple Juice | 中心周囲 `3 x 3` の果物を消す |
| Orange Juice | 中心行の果物を消す |
| Lemon Juice | 中心周辺の最大4個を現在の軸果物に変える |
| Grape Juice | 中心列の果物を消す |
| Melon Juice | 着地点を中心にひし形範囲を消し、次の1手を遅くして消去スコアを `1.5x` にする |
| Berry Juice | 盤面で最も多い果物に、中心周辺の最大5個を変える |

ジュース効果の中心はボトルの着地点です。盤面が高く積み上がっている時は、ボトルを上部で割って切り返すこともできます。

着弾時には、効果で変化したセル数やジュースの種類に応じたボーナスも入ります。効果によって4個以上がつながれば、そのまま通常の連鎖と次のプレスへつながります。

## 演出

幻想的な工房の背景に合わせ、果物・コルク栓の果汁瓶・水滴は手描き風のスプライトです。果物は色だけでなく形でも見分けられます（Berry はイチゴ）。果物は着地時に短く弾み、消去時には圧縮から飛沫へつながります。Press Tankの大きな瓶は次の瓶の進捗、小さな瓶と `NEXT` は完成済みの在庫を表します。

効果音は、jsfxr の合成音に、果物や連鎖の段で音程が変わる下降する正弦波の「ポコッ」という共鳴音を重ねて、みずみずしさを出しています。ボトル着弾・水が降る・水が消える・スピードアップの4種だけは、SFX Forge で生成した音に同じ共鳴音を重ねています。BGMはヘ長調・テンポ128の明るい工房の曲で、マリンバ風の旋律、裏拍で刻む和音、弾む8分のベース、スネアとハイハットのリズムで構成しています。ボトル完成待ちには泡のアルペジオが加わり、ボトル落下中はリズムが前に出ます。

設計と責務の分担は [Juice Workshop design](docs/juice-workshop-design.md) を参照してください。

連鎖、ボトル完成、Juice Dropの着弾、ゲーム進行段階の変化には、盤面上の光、波紋、スプラッシュ、スコア表示、SFX/BGMの変化が入ります。

- 連鎖は「消える → 落ちる → 次が消える」の順に1段ずつ再生され、果物は元の位置から落下して着地時に弾みます。
- HUDの `Chain` は再生に合わせて1段ずつ増えます。
- スコア（チャレンジ中は進捗）は `Next Drop` の横にも表示され、スマホでもスクロールせずに確認できます。
- 2連鎖以上ではチェーン数が盤面中央に表示され、3連鎖以上ではより大きなスプラッシュとコンボ演出が入ります。表示は最新の連鎖だけに出ます。
- 盤面の底にたまった果汁は連鎖で波立ち、ボトルが完成すると水位が下がります。
- ボトルが完成すると `Press Tank` が `NEXT` 表示になり、`Next Drop` にボトルが現れます。
- ボトル着弾時は効果中心から果汁の波紋と粒子が広がり、対象セルが少ない場合でも使用したことが分かる演出が入ります。
- プレイ時間による進行段階が上がるとBGMテンポが変わり、盤面外周に `SPEED UP` のパルスが出ます。
- 通常時は長く聴ける落ち着いたミックス、ボトル完成待ちは高音の果汁アルペジオ、Juice Drop中はリズムとアルペジオが前に出るミックスへ滑らかに変化します。
- `Score Attack`, `Chain Challenge`, `Water Cleanup` では、それぞれテンポとメロディ・ベース・ドラムの重心が変わります。

設定の `演出軽減` またはOSの動きを減らす設定を有効にすると、これらの視覚演出は抑制されます。

## 水

水は果汁を薄める障害物です。同じ水同士では消えず、隣接する果物グループを消した時や、破壊系のJuice Dropに巻き込んで消せます。

- `Normal` と `Score Attack` では、果物ペアを一定数置くごとに水が降ります（ボトルは数えません）。1回に降る数は置いた手数に応じて上限なく増えるので、エンドレスプレイもいずれ終わります。時間ではなく手数で決まるため、手動でもAuto Playでも同じ圧力です。
- 水は連鎖の再生が終わってから、出現位置をふさがない高さに落ちます。`Next Drop` の横に、次に降る水の数と残り手数が表示されます。
- `Water Cleanup` では開始時に水が30個出現し、追加の水は降りません。すべて消すまでのタイムを競います。`Chain Challenge` にも水は降りません。

## 開発

依存関係のインストール:

```bash
bun install
```

効果音の再生成（SFX Forge が必要です）:

```bash
bun run --cwd <sfx-forge のパス> sfx build "$PWD/sfx.json" --out "$PWD/public/sfx"
```

BGM MIDIの生成:

```bash
bun run generate:bgm
```

ローカル開発サーバー:

```bash
bun run dev
```

本番ビルド:

```bash
bun run build
```

ビルド成果物の確認:

```bash
bun run preview
```

単体テスト:

```bash
bun run test
```

カバレッジ確認:

```bash
bun run test:coverage
```

ブラウザ、描画、音を起動せず、ゲームモデルとAIだけで決定論的な長時間検証を行う場合:

```bash
bun run simulate:ai -- --mode chainChallenge --rounds 100 --seed 1
```

各ラウンドの終了理由、スコア、完成したボトル数、降った水の数、盤面の平均最大高さ、チェインが伸びた時刻、最大チェイン、判断回数、判断時間、仮想チェイン解析回数を出力します。バランス調整では `--mode normal --max-ms 900000` のように長めに回すと、ゲームオーバーまでの時間も比較できます。同じseedは同じNext Drop列になるため、AI変更前後の比較や停止盤面の再現に利用できます。`Chain Challenge` の1ラウンドは仕様どおり60秒で、`challengeComplete` は正常なタイムアップ、`topOut` は盤面上詰まりです。水の圧力がある `Normal` と `Score Attack` では `topOut` は想定内の結果で、終了コードは失敗になりません。`--json`を付けると5秒ごとの盤面指標、チェイン更新時の盤面、最終盤面を含むJSONを出力します。

E2Eテスト:

```bash
bun run test:e2e
```
